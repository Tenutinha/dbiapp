Dúvidas

Perguntas frequentes

Preciso ter licença de Power BI ou QlikView?

A proposta é que você consuma os dashboards pela própria plataforma. Os modelos foram desenhados nessas ferramentas e trazidos para cá com as mesmas medidas e lógica de negócio.

E se meus dados não estiverem em Parquet?

Você pode enviar CSV ou Excel. Na chegada, a plataforma valida o schema e converte para Parquet automaticamente, já com os tipos corretos.

Como sei quais arquivos cada dashboard precisa?

Cada dashboard tem um contrato de dados: lista de tabelas fato e dimensão, colunas obrigatórias, tipos e chaves. Dá pra baixar um modelo de exemplo antes de subir.

Meus dados ficam visíveis para outros assinantes?

Não. Cada assinante tem um workspace isolado. Só vê os dados quem você convidar ou quem tiver o link que você gerou.

Consigo atualizar os dados todo mês?

Sim. Suba só o período novo; a carga é incremental e versionada, então o dashboard continua funcionando enquanto a atualização acontece.
